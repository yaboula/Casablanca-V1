## Claude Code adapter

Use the multi-agent workspace defined in `.agents/`.

For non-trivial tasks:
- start from `.agents/activation-guide.md`
- use PM Orchestrator
- create a Task Packet
- follow the selected workflow
- respect blocking rules
- produce a Handoff Summary

Do not bypass `.agents/rules/`.
Do not install dependencies without explicit user approval.
Do not close implementation tasks without QA.
